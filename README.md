# Elijah Crisehea Nollen - Portfolio Website

This repository contains my interactive portfolio and its Supabase-backed guestbook.

## Overview
The portfolio is designed as an interactive, visual-first experience that combines:
- Personal profile and background
- Education timeline
- IT experience and skills
- Goals and aspirations
- Hobbies showcase
- Picture gallery
- Live guestbook wall

## Tech Stack
- Portfolio: HTML, CSS, vanilla JavaScript, Canvas, and original pixel art
- Guestbook API: NestJS and TypeScript
- Database: Supabase
- Hosting: Vercel

## Project Structure
- `dreamtown/` - source for the live interactive portfolio
- `frontend/` - Vercel build wrapper and same-origin guestbook route; its earlier React source is inactive
- `backend/` - NestJS guestbook API and a copy of the portfolio in `public/`
- `introduction/` - initial static reference files
