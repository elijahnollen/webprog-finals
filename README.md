# Elijah Crisehea Nollen - Portfolio Website

This repository contains my interactive portfolio and its Supabase-backed guestbook.

## Overview
The portfolio is designed as an interactive, visual-first experience that combines:
- Personal profile and background
- Education timeline
- IT experience and skills
- Goals and aspirations
- Hobbies showcase
- Picture gallery
- Live guestbook wall

## Tech Stack
- Portfolio: HTML, CSS, JavaScript, and original pixel art
- Earlier frontend: React and TypeScript (`frontend/`)
- Backend: NestJS
- Database: Supabase
- Hosting: Vercel

## Project Structure
- `frontend/` - portfolio UI and interactions
- `backend/` - Vercel guestbook API and the current portfolio in `public/`
- `dreamtown/` - interactive portfolio source and content notes
- `introduction/` - initial static reference files
