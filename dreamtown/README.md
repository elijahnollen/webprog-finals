# Eli’s Dreamtown

A standalone pink pixel-art portfolio built from the personal content in frontend/src/models/content.ts.

## Preview

From the repository root run `python -m http.server 4173 --directory dreamtown`, then open http://localhost:4173.

No build step or dependencies are required. Use WASD or arrow keys to walk, E to interact, or click a destination. Each building has a walkable interior. The directory is a keyboard-accessible alternative. Mobile has touch controls.

## Edit

- `content.js`: personal information, skills, education, favorites, and links.
- `app.js`: town, room layouts, interactions, and original pixel scenery.
- `style.css`: pink theme, start screen, overlays, responsive controls.

The old frontend and backend are preserved. This standalone version does not connect to or modify the original guestbook database.

External fonts: DM Sans and Playfair Display via Google Fonts. Photographs and media cover images are reused from the original portfolio.
