# Dreamtown art

Two original transparent sprite atlases were generated with the built-in image generation tool and integrated as canvas sprites. The original reference site's artwork was not copied.

## Buildings and furniture prompt

Production sprite atlas for a pink feminine top-down pixel-art RPG portfolio game. Four columns by four rows on transparent background. Rich hand-pixelled classic 16-bit RPG art, crisp edges, fine clusters, layered shading, detailed wood and tile textures. Rose, blush, ivory, lilac, mint, sage, golden highlights. Top-down three-quarter view, no isometric angles. Eight centered-door buildings: ornate pink Victorian dreamhouse, lilac academy, mint analytics studio, pink cinema, lilac glass conservatory, peach photography cottage, dusty-pink artist atelier, coral-pink post office. Eight furniture sprites: tufted pink sofa, pastel-filled walnut bookshelf, ivory dual-monitor desk, pink vanity, cinema screen and seats, photo display, trophy cabinet, stationery desk. No text, numbers, grid, or watermark.

## Garden decoration prompt

Production sprite atlas for a detailed feminine pink top-down 16-bit RPG game. Four columns by two rows on transparent background. Crisp tiny hand-pixelled details, sophisticated palette, hard pixel edges, layered shading. Pink cherry blossom tree; leafy green tree; ivory-and-rose fountain with aqua water; pink-and-ivory garden bench; Victorian lamppost with hanging roses; rose garden with white picket border; leafy potted plant in a pink-and-gold pot; outdoor cafe table and two chairs. No text, grid, lettering, or backdrop.

## Assets

- `img/dreamtown-sprites.png`: buildings and furniture.
- `img/dreamtown-decor.png`: garden and decor.

Existing photographs and movie and book covers are reused from the original repository. The canvas terrain, room architecture, character, and interface are implemented in code. The atlases are original generated art; the text above records the production briefs.


## Detailed furnishing atlas v2

Generated with the built-in image generation tool, with transparent background enabled. Project asset: `img/dreamtown-props-v2.png`. The 16 distinct props are used in both the town cutaways and walkable interiors. Explicit sprite crops prevent neighboring cells from bleeding into each other.
