Only a high-level professional summary is published; no internal project files, private repository contents, patient information, or ChatGPT conversation links are included.

The primary reading route is About → Selected work → Skills → Background → Contact. Gallery, Interests, and Direction remain available as optional personal sections. Game rooms and the reading view use the same content definitions.
